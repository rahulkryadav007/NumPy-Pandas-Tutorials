# NumPy Statistical Functions

## Example

```python
import numpy as np

marks = np.array([65,78,90,85,72])

print(np.sum(marks))
print(np.mean(marks))
print(np.max(marks))
print(np.min(marks))
print(np.std(marks))
print(np.var(marks))
```

## Hinglish
Large numerical data ka quick summary nikalne ke liye statistical functions use hote hain.

## Real-Life
Class ke total marks, average marks aur highest marks find karna.

## Important Functions
sum, mean, median, max, min, std, var.
