# NumPy Array Operations

NumPy element-wise operations fast way mein perform karta hai.

```python
import numpy as np

arr = np.array([10,20,30])

print(arr + 5)
print(arr - 5)
print(arr * 2)
print(arr / 2)
print(arr ** 2)
```

## Array vs Array

```python
a = np.array([1,2,3])
b = np.array([4,5,6])

print(a + b)
print(a * b)
```
