# Reshape and Flatten

## Reshape

```python
import numpy as np
arr = np.array([1,2,3,4,5,6])

matrix = arr.reshape(2,3)
print(matrix)
```

## Flatten

```python
print(matrix.flatten())
```

### Hinglish
Reshape same data ko new rows aur columns mein arrange karta hai.
