# Combining Arrays

## Concatenate

```python
import numpy as np

a = np.array([1,2,3])
b = np.array([4,5,6])

print(np.concatenate((a,b)))
```

## Vertical Stack

```python
print(np.vstack((a,b)))
```

## Horizontal Stack

```python
print(np.hstack((a,b)))
```
