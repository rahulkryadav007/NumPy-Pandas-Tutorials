# NumPy Mathematical Functions

```python
import numpy as np

arr = np.array([1,4,9,16])

print(np.sqrt(arr))
print(np.power(arr, 2))
print(np.abs([-2,-5,3]))
print(np.round([1.2,2.8]))
print(np.floor([1.9,2.1]))
print(np.ceil([1.1,2.9]))
```

## Important Functions
- `np.sqrt()`
- `np.power()`
- `np.abs()`
- `np.round()`
- `np.floor()`
- `np.ceil()`
- `np.exp()`
- `np.log()`
